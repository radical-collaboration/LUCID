# LUCID: Low-Dose Understanding, Cellular Insights, and Molecular Discoveries

Infrastructure supported tools and components for runtime system capabilities 
to integrate HPC and ML technologies[^1], prototypes and evaluation of the initial 
set of capabilities at scale with representative workloads.

Shared space for the variety of LUCID use cases data, including source code, 
datasets, instructions for different tools setup and execution, and 
documentation.

[^1]: Andre Merzky, Mikhail Titov, Matteo Turilli, Ozgur Kilic, Tianle Wang, 
and Shantenu Jha. (2025). Scalable Runtime Architecture for Data-driven, 
Hybrid HPC and ML Workflow Applications. https://arxiv.org/abs/2503.13343
